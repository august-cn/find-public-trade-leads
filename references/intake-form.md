# Seven-part intake

Use this form when any required field is missing. Preserve the user's language.

```markdown
请填写以下 7 项信息。第 1 项可以填写文字、粘贴产品网址，或直接上传产品介绍文件。

1. 产品
   - 产品名称/类别：
   - 产品网址或附件：
   - 主要用途、规格、材质、认证、包装、优势（知道多少填多少）：

2. 目标市场
   - 国家、地区或城市：

3. 合作方式
   - 例如：OEM、ODM、自有品牌、代理、批发、项目供货：

4. 供货能力
   - 例如：MOQ、混装、整柜、交期、月产能、可提供的认证或文件：

5. 客户规模
   - 希望的员工数、营收、门店/仓库数量或“小型/中型/大型”：

6. 参考品牌
   - 品牌、竞争对手或希望进入的渠道：

7. 排除
   - 不要的客户类型、公司、地区、渠道或规模：

可选：目标客户数量（默认 20 家）：
```

## Completeness rules

- Accept concise answers; do not force unknown specifications.
- Treat a readable product URL or attachment as sufficient product input when it provides the missing details.
- Ask again only for fields that remain materially empty after reading supplied URLs or files.
- Do not add an eighth mandatory field.
- Default the result count to 20 when omitted.
